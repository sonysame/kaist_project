# PRD: 영어 오디오 대본·번역 학습 앱

## 1. 배경
영어 오디오 파일을 대본으로 보고, 한국어 뜻도 함께 확인하고 싶다.

## 2. 사용자
영어 공부를 하려는 사람들

## 3. 핵심 시나리오
1. 사용자가 영어 오디오 파일을 올린다.
2. 화자가 분리된 영어 대본이 나온다.
3. 문장에 마우스를 올리면 한국어 번역이 보인다.
4. 모르는 단어를 클릭하면 문맥에 맞는 뜻이 나오고, 단어장에 저장할 수 있다.

## 4. 데이터
| 데이터 | 저장 위치 | 비고 |
|---|---|---|
| 압축한 오디오 (16kHz 모노 MP3) | Supabase Storage `audio` 버킷 | 재생용, 파일당 50MB 이하 |
| 작업, 구간, 발화(영어·한국어·단어 타임스탬프) | Supabase DB `jobs`, `chunks`, `utterances` | |
| 단어장 (단어, 뜻, 예문, 출처 시각) | Supabase DB `vocab` | 브라우저별 익명 ID로 구분 |

## 5. 화면
1. **업로드 화면** (`/`): 파일 끌어 놓기 또는 선택, 진행률 표시, 최근 작업 목록
2. **대본 화면** (`/jobs/[id]`): 오디오 플레이어, 화자별 대본, 마우스를 올리면 한국어 표시, 단어 클릭 시 뜻과 저장 버튼, 재생 위치 강조, TXT/SRT 내보내기
3. **단어장 화면** (`/vocab`): 저장한 단어, 뜻, 예문, 원래 위치로 이동, 삭제
   - 학습용 플레이어: 재생 속도(0.75~1.25배), 5초 앞뒤 이동, 문장 반복, "이 문장만 듣기"
   - 단어 뜻 창의 발음 듣기(브라우저 내장 음성)
   - 단어장의 "카드로 외우기"(뒤집기, 섞기)
   - 단어장의 "퀴즈": 뜻 고르기 / 단어 고르기 / 빈칸 채우기(원래 대본 문장) 4지선다, 최대 10문제, 결과와 틀린 단어 다시 풀기 (단어 4개 이상 필요)
4. (선택) **캐릭터로 보기**: 대본 화면 → 내보내기 → "캐릭터로 보기"
   - 파일로 저장하지 않고, 대본 화면의 오디오에 맞춰 화면에서 실시간으로 그린다 (녹화 기능은 사용자 요청으로 뺌)
   - 화자마다 오리지널 털복숭이 캐릭터가 말할 때 입을 움직임 / 자막만, 가로 · 세로, 해석 켜기 · 끄기, 전체 화면
   - 단어 따라가기 강조는 넣지 않는다. 숨긴 광고는 재생할 때도 건너뛴다
   - 저작권 때문에 세서미 스트리트 등 기존 캐릭터는 쓰지 않는다

## 6. 제약과 결정
- 하루 안에 만든다. **로그인은 넣지 않는다.**
  - 대신 단어장은 브라우저마다 익명 ID(localStorage)로 구분한다. 브라우저를 바꾸거나 데이터를 지우면 단어장이 보이지 않는다.
  - 작업 목록과 대본은 링크를 아는 누구나 볼 수 있다. 배포 주소가 퍼지면 다른 사람이 Gemini 무료 한도를 쓸 수 있다. 필요하면 나중에 간단한 접속 코드를 추가한다.
- 무료 모델만 쓴다: 전사·화자 분리는 `gemini-3.5-transcribe`, 번역과 단어 뜻은 `gemini-3.5-flash-lite` (3.8-flash는 무료 등급에서 너무 느림) (Gemini API 무료 등급)
  - 무료 등급에 보낸 데이터는 Google이 제품 개선에 쓸 수 있다.
  - 하루 요청 수 제한이 있어서 긴 파일은 한도에 걸리면 나중에 이어서 처리한다.
- 배포: Vercel (함수 최대 300초), DB와 파일: Supabase 무료 플랜

## 7. 완료 기준
아래가 모두 되면 "다 만들었다"고 본다.
1. `audio.mp3`(약 111MB)를 올리면 압축, 업로드, 처리가 오류 없이 끝까지 진행된다.
2. 대본에 화자가 2명 이상 구분되어 나오고, 같은 사람은 20분 구간이 바뀌어도 같은 화자로 이어진다.
3. 모든 문장에 한국어 번역이 있고, 마우스를 올리면 보인다.
4. 문장의 시각을 누르면 그 위치부터 재생되고, 재생 중인 문장이 강조된다.
5. 단어를 클릭하면 문맥에 맞는 한국어 뜻이 나오고, 저장하면 단어장에 보인다. 새로고침해도 남아 있다.
6. 처리 도중 창을 닫았다가 다시 열면 멈춘 곳부터 이어서 처리된다.
7. Vercel 배포 주소에서 1~6이 똑같이 된다.

선택 기능(자막 영상)은 완료 기준에 넣지 않는다.

## 8. 테스트 결과 (2026-10-20, 로컬)
`audio.mp3` (Acquired 팟캐스트 Tencent 편, 1시간 56분, 111MB)

| 단계 | 결과 |
|---|---|
| 브라우저 압축 | 57초, 111MB → 27.8MB |
| 처리 전체 | 6구간, 구간당 전사 약 60초 + 번역 약 20초 |
| 대본 | 498문장, 단어 21,510개, 구간 경계 중복·누락 없음 |
| 번역 | 497/498문장 (1문장은 모델이 빠뜨려 "번역 없음") |
| 화자 | 진행자 2명이 전 구간에서 이어짐. 광고 부분(따로 녹음)은 별도 화자 2명으로 잡힘 |
| 이어서 처리 | 처리 중 새로고침해도 멈춘 곳부터 이어짐 |
| 단어장 | 클릭 → 뜻(약 8초) → 저장 → 단어장에 표시 |

### 광고 숨기기와 화자 이름 (추가)
- 모든 구간이 끝나면 대본 전체를 한 번 더 읽어 광고 문장을 표시하고(기본은 숨김, "광고 보기"로 다시 볼 수 있음), 자기소개나 서로 부르는 말로 화자 이름을 넣는다. 같은 이름이 붙은 화자는 자동으로 합친다.
- 테스트 결과: 광고 4개(37문장, 2초), 이름 Ben Gilbert / David Rosenthal → 화자 2명, 본편 461문장

### 알려진 한계
- 모델이 한 구간 안에서 같은 사람을 둘로 나누는 경우가 있다 → 대본 화면에서 **화자 합치기**로 직접 고친다.
- 화자 분리를 켜면 단어 힌트(custom vocabulary)를 쓸 수 없어 고유명사를 틀릴 수 있다 (예: Tencent → "10 Cent").
  → 마무리 단계에서 `gemini-3.5-flash`로 고유명사 교정을 따로 요청해 대본과 그 녹음의 단어장 예문을 고친다.
  flash-lite는 광고 속 실제 제품명까지 엉뚱하게 바꿔서 쓰지 않는다. 이 녹음에서는 10 Cent → Tencent(32곳), Metalk → MiTalk(2곳)를 고쳤다.
